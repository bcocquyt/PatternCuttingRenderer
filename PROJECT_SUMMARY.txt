QUICK START
═══════════════════════════════════════════════════════════════════════

Prerequisites:
  1. .NET 9.0 SDK
  2. MAUI workload: dotnet workload install maui
  3. IDE (Visual Studio 2022 or VS Code)

Build & Run:
  $ git clone https://github.com/bcocquyt/PatternCuttingRenderer.git
  $ cd PatternCuttingRenderer
  $ dotnet restore
  $ dotnet run -f net9.0-windows10.0.19041.0     # Windows
  $ dotnet run -f net9.0-android                  # Android

For detailed instructions, see QUICKSTART.md
